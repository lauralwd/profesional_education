# 🖥️ Linux & HPC for Research

## 📝 Course Overview

With the rise of **big data, AI, and bioinformatics**, knowing how to work with **Linux and High-Performance Computing (HPC)** is becoming an important skill for researchers. This course provides a **hands-on introduction** to Linux and HPC, designed for researchers who need to dive into the world of Linux aiming to process large datasets, automate tasks, and manage computational resources effectively.

This course was formerly known as **Introduction to Command Line** but has been expanded based on feedback to include more **HPC-related content and practical scripting exercises**.

🚀 **This course is part of the GS-LS bioinformatics Linux learning line.** Completing it will strengthen your computational skills and prepare you for **more advanced courses in scientific computing and workflow automation**.

## 🎯 Learning Objectives

- Gain confidence in using the **Linux command line**.
- Learn essential **file navigation, permissions, and text processing**.
- Understand how to **install software and manage dependencies**.
- Write **basic Bash scripts** to automate tasks.
- Learn **SSH and remote computing** for working on HPC clusters.
- Practice **data processing, workflow scripting, and job submission**.

Note that this course does not provide HPC access, but we will practice all basic skills needed for using a HPC.

## 🧰 Prerequisites

- No prior experience with Linux is required, but familiarity with basic coding concepts is helpful.
- Participants should **bring a laptop with a terminal installed** 
  - Windows users will need WSL, git bash, or a remote server setup.
  - Mac users can use the build-in terminal
  - Chromebook users need the crostini Linux VM
  - Linux users need only their laptop!

## 💻 Tools and Resources

- **Software:** Linux terminal, Bash scripting, SSH, and HPC job schedulers.
- **Course materials:** Interactive lessons, cheat sheets, and example scripts.
